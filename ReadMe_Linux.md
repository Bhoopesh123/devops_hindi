# 1. File & Directory Management

    ls → files & folders list karne ke liye  
    cd → directory change karne ke liye  
    pwd → current directory path  
    mkdir → new folder create  
    rm -rf → delete (⚠️ carefully use)  
    cp, mv → copy & move  

# 2. File Viewing & Editing  

    cat → file content show  
    less → scrollable view  
    head, tail -f → logs monitoring  
    vim / nano → edit files  

# 3. User & Permissions  

    chmod → permissions change
    chown → ownership change
    sudo → admin access
