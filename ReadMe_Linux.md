# 1. File & Directory Management

    ls → files & folders list karne ke liye  
    cd → directory change karne ke liye  
    pwd → current directory path  
    mkdir → new folder create  
    rm -rf → delete (⚠️ carefully use)  
    cp, mv → copy & move  

# 2. File Viewing & Editing  

    cat → file content show  
    less → scrollable view  
    head, tail -f → logs monitoring  
    vim / nano → edit files  

# 3. User & Permissions  

    chmod → permissions change
    chown → ownership change
    sudo → admin access

# 4. Process Management 

    ps aux → running processes
    top / htop → system monitoring
    kill, kill -9 → stop process

# 5. Networking Commands

    ping → connectivity check
    curl → API calls test
    netstat / ss → open ports
    wget → download files

# 6. Disk & System Info

    df -h → disk usage
    du -sh → folder size
    free -m → memory usage
    uptime → system load

# 7. Package Management (Ubuntu / RHEL)

    apt update, apt install (Ubuntu)
    yum install / dnf install (RHEL)

# 8. Search & Text Processing (🔥 Powerful)

    grep → search inside files
    find → file search
    awk, sed → text processing

# 9. Archiving & Compression

    tar -cvf → archive create
    tar -xvf → extract
    zip, unzip

# 10. SSH & Remote Access

    ssh user@ip → remote login
    scp → file transfer

# 11. Pro Tips (Real DevOps Flavor)

    history | grep docker → past commands search
    alias → shortcuts bana lo (time saver)
    watch → continuous monitoring
    crontab -e → automation jobs
